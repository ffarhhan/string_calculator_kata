# 🧮 String Calculator – TDD Kata

This is a simple Ruby implementation of the classic **String Calculator Kata**, built entirely using **Test-Driven Development (TDD)**. The purpose is to showcase disciplined TDD practice, clean commits, and readable code.

---

## 📦 Tech Stack

- **Ruby** (no Rails)
- **RSpec** for testing

---

## ✅ Requirements Implemented

| Step | Behavior |
|------|----------|
| 1 | Returns 0 for an empty string |
| 2 | Returns the number itself for a single number |
| 3 | Returns the sum of two comma-separated numbers |
| 4 | Returns the sum of multiple comma-separated numbers |
| 5 | Supports newline `\\n` as a valid delimiter |
| 6 | Supports custom delimiter in format `//<delimiter>\\n` |
| 7 | Raises exception for negative numbers |
| 8 | Refactored for clean, readable logic |
